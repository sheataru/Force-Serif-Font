# Force-Serif-Font
Changes all fonts on web pages to the default, serif.
# Install Instructions!
<h1><font color="red">C</font><font color="green">h</font><font color="yellow">r</font><font color="blue">o</font><font color="red">m</font><font color="green">e</font></h1>
  1. Download the source files.  
  2. Open Chrome and go to chrome://extensions/.  
  3. Enable "Developer mode" in the top-right corner.  
  4. Click "Load unpacked" and select the folder where the extension files are stored (manifest.json, styles.css).  
<h1>Firefox</h1>
  1. Download the source files.  
  2. Open Firefox and go to about:debugging.  
  3. Click on "This Firefox" in the left sidebar.  
  4. Click "Load Temporary Add-on" and select the manifest.json file from the extension folder.
